# agent management

## setup new
command: agent-setup
where to run: in the main repo
what it does when it runs:
- if exists (likely untracked): .profile. read all answers, if all are there create. otherwise do the things. 
- creates a new workspace from current repo in ~/.agents/worktrees/{repositoryName}/{randomUniqueName}/{repoRootHere}
- asks for template, or requirements:
  - template: can be like 'lastest'
  - requirements (nice to have): php: 7.5, MySQL: latest
- if exists in repo: '.worktreeignore', copy all .gitignore, except those. otherwise ask which ones to copy from the .gitignore
- ask wich ones to copy from .git/info/exclude
