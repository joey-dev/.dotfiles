# create sandbox from pwd using command
- Command to create a brwap from current position 
- with claude files added
- starts by default in the same shell ($SHELL)
- startup can be changed with the --startup flag:
  - example: --startup="bash"
  - any executable file can be added here, including parameters.
- for agents, it's reccomended to use --agent-claude, instead of --startup, as this will make sure the model, permissions, etc is set as expected
- flag --network-access is required:
    - `--network-access false`, disables all internet access to the outside world, except to specific endpoints: ("api.anthropic.com", "platform.claude.com"), on port 443, as these are required
    - `--network-access true`, enables all internet access. making it a bit less secure
