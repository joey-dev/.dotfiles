# Intake Stage

1. Use Atlassian MCP tools to fetch the target Jira ticket, its comments, and any linked issues.
2. Write `01-ticket.md` in the ticket state directory with:
   - **Summary & Issue Type**
   - **Acceptance Criteria**
   - **Key Comments & Decisions**
   - **Linked Issues / Dependencies**
   - **Initial Ambiguities** (to verify during Explore / Q&A)
